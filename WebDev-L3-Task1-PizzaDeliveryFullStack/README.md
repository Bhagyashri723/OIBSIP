## 🍕 WebDev-L3-Task1 — Pizza Delivery Full Stack

A full-stack Pizza Delivery web application developed as part of the Oasis Infobyte Web Development Internship.

### 🛠️ Technologies Used
- React.js
- Vite
- CSS3
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- REST API

### ✨ Features
- User Registration & Login
- Secure Authentication
- Pizza Menu & Product Listing
- Shopping Cart
- Order Placement
- Order Management
- Admin Panel
- Backend REST APIs
- MongoDB Database Integration
- Responsive User Interface

### 📁 Project Structure
WebDev-L3-Task1-PizzaDeliveryFullStack/
├── frontend/
└── backend/

### 🚀 How to Run

1. Start the Backend:
   cd WebDev-L3-Task1-PizzaDeliveryFullStack/backend
   npm install
   copy .env.example .env
   npm run dev

2. Start the Frontend in a new terminal:
   cd WebDev-L3-Task1-PizzaDeliveryFullStack/frontend
   npm install
   npm run dev

### 🗄️ Database Setup
MongoDB must be running locally.

Configure the required environment variables in:
backend/.env

Do not upload .env or secret credentials to GitHub.

### 🌐 Local Development
Frontend: http://localhost:5174
Backend: http://localhost:5000
