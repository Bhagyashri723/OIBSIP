# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website developed using React and Vite to showcase my skills, projects, education, and professional profile.

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Responsive Web Design

## ✨ Features

- Professional Hero Section
- About Me Section
- Skills & Technologies
- Projects Showcase
- Education Details
- Contact Section
- Responsive Design
- Modern and User-Friendly Interface

## 📁 Project Structure

WebDev-L1-Task2-PersonalPortfolio/
├── src/

├── index.html
├── package.json
└── vite.config.js

## 🚀 How to Run

npm install
npm run dev

Open the local URL shown in the terminal to view the portfolio.
