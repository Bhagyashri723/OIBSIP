# Aurora — Professional Landing Page

A polished, responsive static landing page built for Task 1 using only HTML5 and CSS3.

## Features
- Sticky responsive navigation
- Hero section with CTA
- Dashboard-style visual made entirely with HTML/CSS/SVG
- Features, About, Testimonials, CTA and Footer sections
- Consistent purple/neutral visual system
- Responsive layouts for tablet and mobile
- Google Fonts: Space Grotesk + DM Sans
- No JavaScript required

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.

For the best development experience, open the folder in VS Code and use Live Server.
