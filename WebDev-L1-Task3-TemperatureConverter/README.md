# Tempora — Temperature Converter

A professional, responsive temperature converter made with **HTML5, CSS3 and Vanilla JavaScript**.

## Features
- Celsius, Fahrenheit and Kelvin input selection
- Converts to all three units at once
- Convert button triggers calculation
- Numeric input validation
- Friendly error messages
- Absolute zero validation
- Responsive mobile layout
- Clean centered UI
- No JavaScript frameworks

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or simply double-click `index.html`.

## Files
- `index.html` — page structure
- `style.css` — complete responsive styling
- `script.js` — conversion logic and validation

## Conversion formulas
- Celsius → Fahrenheit: `(C × 9/5) + 32`
- Fahrenheit → Celsius: `(F − 32) × 5/9`
- Celsius → Kelvin: `C + 273.15`
- Kelvin → Celsius: `K − 273.15`
